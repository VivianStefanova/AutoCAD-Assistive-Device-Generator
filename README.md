# AutoCAD Assistive Device Generator

## Introduction

The following two AutoCAD programs demonstrate how parametric modeling can be used to create assistive devices for people with reduced hand dexterity.

The programs introduce two types of assistive devices:

* **Pinky** – a sphere-like holder for pens and pencils.
* **Cup Holder** – a cup holder with more comfortable handles.

Both programs include simple user interfaces for changing the model parameters. This makes the project easy to use even for people without previous AutoCAD experience, such as caregivers and rehabilitation specialists.

## Project Structure

The two main programs are **Pinky** and **Cup Holder**.

### Pinky

* `Pinky.lsp` – Main program code for Pinky.
* `Pinky.DCL` – User interface window for Pinky.
* `Pinky.dwg` – AutoCAD drawing containing the different pen holder models. **The program must be executed from this drawing.**
* `P1.sld` – Slide used by the DCL interface.

### Cup Holder

* `CupHolder.LSP` – Main program code for the Cup Holder.
* `cupHolderWindow.DCL` – User interface window for the Cup Holder.

### Shared Files and Folders

* `VlaUtils.LSP` – Contains the required building functions implemented using the VLA library.
* `Dat/` – Contains account and parameter data.
* `STL/` – Contains STL files generated by the programs.

## Features

### Parametric Modeling

The dimensions of the assistive devices can easily be changed to fit the needs of the user.

### User Interface

The DCL windows included in the programs allow for easy adjustment of the model parameters.

### Customizable Pen and Pencil Holders

The Pinky program allows the creation of **custom blocks** that can be added to the device. These blocks can be designed to accommodate pens and pencils of different sizes, allowing the device to be adapted to the specific needs of the user.

### STL Conversion

The programs can automatically convert the AutoCAD models to STL files for seamless 3D printing.

### VLA Functions

All operations required to build the models use the VLA library, making the programs faster and more reliable.

### Data Entries

The Pinky program allows users to create accounts and save parameter values for specific users. This makes it easier to recreate or modify a previously created model.

## Loading the Project

> **Important:** The project must be saved on the `C:` drive to work properly.
> The project files must be located in:
>
> `C:\Pinky`

### Pinky

1. Open `Pinky.dwg`.

2. Make sure `Pinky.dwg` is the active drawing.

3. Load `Pinky.lsp`.

4. Type the following command in the AutoCAD command line:

   ```text
   Pinky
   ```

5. Press **Enter** to start the program.

### Cup Holder

> **Important:** The project must be saved on the `C:` drive to work properly.
> The project files must be located in:
>
> `C:\Pinky`

1. Open any AutoCAD drawing.

2. Load `CupHolder.LSP`.

3. If AutoCAD displays a pop-up asking for permission to load `VlaUtils.LSP`, allow it.

4. Type the following command in the AutoCAD command line:

   ```text
   CupHolder
   ```

5. Press **Enter** to start the program.
